# Retail Inventory Manager

## About
This is a simple Python project made to manage products in a shop.It helps the user keep track of product details,prices and available stock.The program runs in the terminal and uses a menu to perform different tasks.

## Setup
- Install Python 3 on your system.
- Download the project files.
- Open the project folder in VS Code.
- No extra libraries are needed.

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:
   `python project1.py`
4. Select an option from the menu and follow the instructions.

## Input Rules
- Product ID should be unique.
- Product name and category should not be empty.
- Price must be greater than 0.
- Stock and reorder level cannot be negative.
- Enter a valid menu option.

## Features
- Add new products.
- Display all products.
- Search products using ID.
- Update product details.
- Delete products.
- Check low stock products.
- View inventory summary.

## Known Limitations
- Product data is not permanently saved.
- All data is lost when the program is closed.
- The program works only in the terminal.
- It does not use a database.

## Test Cases
- Add a new product with valid details.
- Try adding a product with an existing ID.
- Search for a product that exists.
- Search for a product that does not exist.
- Update the price or stock of a product.
- Delete a product.
- Check the low stock report.
- View the inventory summary.
