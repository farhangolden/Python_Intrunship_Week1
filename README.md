# Retail Inventory Manager

## Project Overview
Retail Inventory Manager is a simple Python console-based application used to manage products and their stock in a shop. It helps users add, display, search, update, and delete products.

## Features
- Add Product
- Display Products
- Search Product by ID
- Update Product Details
- Delete Product
- Low Stock Report
- Inventory Summary

## Technologies Used
- Python 3
- VS Code
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements

## Product Details
Each product contains:
- Product ID
- Product Name
- Category
- Selling Price
- Stock Quantity
- Reorder Level

## How to Run
1. Install Python on your computer.
2. Download or open the project folder.
3. Open the folder in VS Code.
4. Run the following command in the terminal:
   `python project1.py`
